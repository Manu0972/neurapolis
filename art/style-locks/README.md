# Verrous de style par catégorie

Une catégorie = un style = un workflow. On ne mélange jamais deux catégories dans une même génération.

| Fichier | Couvre | Style |
|---|---|---|
| `personnages.json` | joueur, PNJ, ados, foule (niveau de détail léger) | 3D dessin/anime harmonieuse |
| `fantomes.json` | pop-up des penseurs (Smith, Marx, Ostrom, Hobbes, Taylor…) | pixel art 2D, 48 px animé + buste 128 px |
| `decors.json` | bâtiments, rues, parcs, collège, intérieurs, objets | 3D dessin assortie aux personnages |
| `interface.json` | menus, boutons, icônes, création de personnage | structure Big Ambitions + matières cozy |

Brief lisible : `art/references/STYLE-LOCK-BRIEF.md`. Outils : `tools/style/` (`generate.mjs`, `pixelize.py`, `workflows/`).
